# Platform content specs (verify against current platform docs quarterly)

The enforced numeric limits live in code: `packages/core/src/content/platform-limits.ts`. This table is guidance for writing.

| Channel | Text limit used by linter | Links | Writing guidance |
|---|---|---|---|
| Facebook Page | 63,206 (aim ≤ 400) | Clickable; link preview | Conversational; first line must carry the point |
| Instagram | 2,200 caption; ≤ 30 hashtags (we use ≤ 5) | Not clickable in captions → "link in bio" | Visual-first; carousels for education |
| LinkedIn | 3,000 | Clickable; previews must be supplied by API | Professional insight; no hashtags spam |
| Threads | 500 (verify) ; ≤ 5 links | Clickable | Short, conversational |
| Bluesky | 300 graphemes | Facets for links | Short, plain |
| X | 280 (standard accounts) | **API charges ~$0.20 per post containing a URL (Feb 2026 pricing)** | Prefer no-link posts unless the click matters |
| Google Business Profile | 1,500 | CTA button types (LEARN_MORE, CALL, BOOK…) | Local, practical, offer/event types |
| Pinterest | title 100, description 500 | Destination link | Search-keyword descriptive |
| TikTok / Shorts | script | n/a | Hook in first 2 seconds; captions on screen |
